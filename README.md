## 🚀 Featured Projects

### 🔐 ZK-Vault

**Privacy-focused personal data vault**

> *What if the server could store your data without being able to read it?*

ZK-Vault explores a client-side encryption model where sensitive information is encrypted before being stored by the server.

**Built with:** `Python` `Flask` `MySQL` `Redis` `AES-GCM` `Argon2id`

**Key areas:**

* Client-side encryption concepts
* Password-derived encryption keys
* AES-GCM authenticated encryption
* Argon2id password-based key derivation
* OTP-based authentication
* Session management
* Rate limiting
* CSRF protection
* Security headers
* Encrypted data storage

🔗 **Repository:** [github.com/neerajsait/ZK-Vault](https://github.com/neerajsait/ZK-Vault)
